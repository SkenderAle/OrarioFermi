Amministrazione Orario Fermi

Carica i quattro HTML prodotti dal sistema, controllali e pubblicali nel repository senza modificare il visualizzatore.

1. Nuovi file

Privacy sostegno: l'Admin rimuove automaticamente le iniziali degli alunni prima della pubblicazione. Nel repository pubblico restano soltanto docente, classe e disciplina.
2. Impostazioni GitHub
Il token non viene scritto nei file del sito e non viene salvato. Deve avere permesso Contents: Read and write sul solo repository dell'orario. Username, repository e branch vengono ricordati nel browser.

3. Pubblicazione

Verranno aggiornati in un unico commit: dati/orario_classi.html, dati/orario_docenti.html, dati/orario_sostegno.html e dati/sorveglianze.html.
